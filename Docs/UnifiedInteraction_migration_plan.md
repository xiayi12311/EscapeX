## 基线与边界

迁移前已保存本地提交：`39a8ff4`（抓捕移动修复、测试与记录）、`beb6424`（已有编辑器资产及元数据），分支 `feature/searchable-desk`。未推送。

迁移范围是统一的本地聚焦检测、描边、按钮和目标圆环表现。EscapeX 的玩法由现有服务继续决定：

- 课桌点击“搜索”即请求开始，玩家等待现有服务器读秒；无需一直按住按钮。
- 现有开始距离、离开距离中断、回来重新读秒不变；移开准星不新增取消规则。
- 抽屉动画、内容随机、第5/10次固定纸条与广播、全局计数、单桌/全桌重置不变。
- 被抓后所有课桌重置和计数清零不变。
- 搬运 Tick 修复保持不变；玩家与怪物重合、相机过近问题继续按用户要求暂不处理。
- 首批仅接课桌，囚禁点原生挣脱/救援按钮及怪物逻辑不在本次替换范围。

## 迁移后的职责

| 层 | 负责 | 不承接的职责 |
| --- | --- | --- |
| 玩家本地聚焦管理 | 相机准星检测、遮挡、目标切换、焦点事件和UI生命周期 | 业务判定、计数和随机 |
| 物件展示适配 | 提供锚点、动作文字、展示资格、描边目标 | 保存第二份课桌状态 |
| 统一界面 | 按钮请求、目标标记、圆环，读取服务器时间计算进度 | 客户端读满即宣布成功 |
| 玩家Controller网络入口 | 用实际请求Controller调用既有 `DeskSearchService.StartSearch(gm, desk, pc)` | 接收客户端伪造的PlayerKey、完成结果或奖励 |
| 原有课桌服务与Manager | 校验、读秒、中断、打开、结果、计数、重置与复制 | 新界面的布局与输入 |

统一界面经玩家 Controller 的服务器 RPC 请求开始搜索，服务仍调用同一个 StartSearch，并执行既有距离、生存状态等校验。原生 SearchClick 的显示和点击入口已停用，避免出现重复按钮。

`DeskState` 仍是唯一业务真值。圆环使用 `SearchStartTime` / `SearchEndTime` 和已有服务器世界时间计算，按 `SearcherPlayerId` 限定本地搜索者；不使用源工程每0.03秒累加常数的完成计时。

## 对源实现的取舍

保留相机起点射线、实体遮挡处理思路、Owner忽略列表、聚焦事件、描边、世界位置投影、圆环材质表现。参数改为统一配置；避免沿用配置写0.1秒、实际硬编码0.2秒的分歧。

不迁移 Hospital 房间/病人/药品资格、接受拒绝业务、次数冷却管理、客户端完成业务回调，也不把整套YXUtils/UGCGameData表搬入EscapeX。所需描边、投影和资源类引用使用本项目局部实现与明确资源路径。

焦点与正在搜索的目标分别保存：

- 点击开始时保存明确目标并发请求；服务器确认Searching前不得宣告成功。
- 切换准星目标不会把已开始搜索转给另一个物件，也不取消现有搜索。
- 服务器取消、打开、重置、玩家失效或目标销毁时立即清除对应进度与引用。
- 已在读秒时禁用重复开始按钮；完成、取消后按最新复制状态重新评估聚焦。
- 所有检测/界面刷新定时器在Owner结束、UI销毁或关闭时清理。隐藏控件不能代替取消定时器。

## 执行顺序与验收

1. 核对完整资源包与依赖。将源蓝图引用的医院路径、父类、Widget嵌套、动态材质参数列清；缺资源先取得明确来源。
2. 在独立命名空间建立EscapeX聚焦/界面层，绑定现有Pawn生命周期；只在本地所属玩家运行检测。
3. 完成课桌展示适配与玩家Controller开始请求。保留DeskSearchManager/DeskSearchService的业务规则与随机计数逻辑。
4. 接入服务器进度圆环和目标锚点，处理切目标、移开准星、重置、销毁及死亡生命周期。
5. 确认新入口完整可用后，停用课桌旧SearchClick按钮显示及旧进度UI，避免双按钮与双进度；不让两种入口同时提交请求。
6. 分阶段原生验证后提交；不改地图与无关资产，不在迁移期间替其他任务保存资产。

验收清单：

- 近处对准课桌出现一个“搜索”按钮与描边；墙后不出现，目标切换无残留。
- 点击一次开始服务器读秒；松手、移开视线不新增取消行为；越过现有取消距离立即中断，返回重新读秒。
- 圆环跟随正确课桌，分辨率/DPI变化后位置正确；始终依据服务器时间，不提前完成。
- 从A切到B不会把A的进度或请求转给B；未被服务器接受的请求无完成表现。
- 多玩家同时操作遵守现有互斥，不影响他人UI；重复点击只形成有效的一次开始。
- 第5/10次结果、随机内容、抽屉演出和广播与迁移前一致。
- 单桌重置、全桌重置、被抓重置及计数归零立即清掉旧进度；旧回调不能重新显示。
- 死亡、重生、离场、目标销毁后无悬挂定时器或描边。
- 原有抓捕/课桌测试继续通过；原生PIE确认按钮、遮挡、圆环和多人结果。
