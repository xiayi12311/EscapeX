# 两次搜索生成班主任

将 `BP_DeskCountTeacherSpawner` 放入地图；其 `SpawnPoint` 的位置和朝向决定班主任生成变换。每张地图只放一个生成点。必须确认该位置在可站立且可寻路的区域，具体行为以 PIE 实测为准。

服务端确认课桌搜索成功时计数递增；当本次事件的计数为 2，调用 `UGCMobPawnSystem.SpawnMob` 生成 `TheHeadTeacher`。取消搜索不计数；同一对局最多成功生成一次，玩家被抓后的课桌和计数重置不会重置生成标记。如果事件到达时生成点尚未注册，会在该点注册后执行；生成失败会记录错误，不自动反复尝试。事件携带各次计数快照，避免多张课桌同周期完成时漏掉第二次。

已通过 Lua 模拟测试：现有课桌测试、同周期多次搜索计数、生成点延迟注册、重复事件和重复生成点。实际生成位置、班主任 AI、联网表现和计数重置后的不重复生成需在 PIE 中验证。
